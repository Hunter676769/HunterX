# Frontend Design Skill Overview

This skill enables creation of distinctive, production-grade web interfaces that prioritize authentic design over generic aesthetics.

## Core Purpose
The skill guides developers in building "components, pages, artifacts, posters, or applications" with "creative, polished code and UI design that avoids generic AI aesthetics."

## Design Process
Before coding, establish a bold aesthetic direction by considering:
- **Purpose and audience**: Understanding the problem being solved
- **Tone selection**: Choosing from diverse styles like "brutally minimal, maximalist chaos, retro-futuristic, organic/natural, luxury/refined"
- **Technical constraints**: Framework and performance requirements
- **Differentiation**: Creating something "UNFORGETTABLE"

## Key Implementation Standards

The approach emphasizes:
- **Typography**: "distinctive choices that elevate the frontend's aesthetics" rather than generic fonts
- **Cohesive color systems**: Using CSS variables and "dominant colors with sharp accents"
- **Intentional motion**: Strategic animations that create "high-impact moments"
- **Spatial innovation**: "Unexpected layouts. Asymmetry. Overlap. Diagonal flow"
- **Atmospheric details**: Textures, gradients, and custom visual effects

## Critical Caution
Avoid "generic AI-generated aesthetics" including overused typefaces, predictable layouts, and "cookie-cutter design that lacks context-specific character."

The overarching principle: execute your chosen vision with precision and restraint appropriate to the aesthetic direction.
